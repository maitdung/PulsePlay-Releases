# PulsePlay Releases

Kênh phát hành chính thức của PulsePlay do maitdung quản lý.

Repo chỉ chứa thông tin cập nhật và các bản IPA trong GitHub Releases. Không đăng mã nguồn, log cá nhân hoặc thông tin ký ứng dụng.

Chưa có bản phát hành được đăng. Kênh cập nhật chỉ hoạt động sau khi IPA, update.json và altsource.json được xuất bản trong Releases.
