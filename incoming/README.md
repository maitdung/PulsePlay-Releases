# Đăng bản cập nhật

1. Mở https://github.com/maitdung/PulsePlay-Releases/upload/main/incoming
2. Kéo file IPA mới vào, chọn Commit changes lên main.
3. Đợi Actions “Upload IPA to publish” chạy xanh. Bản phát hành và nguồn cập nhật được tạo tự động.

IPA phải tăng số build hoặc phiên bản. Tên file tùy ý; hệ thống đọc phiên bản bên trong IPA. Không tải mã nguồn, chứng chỉ hoặc khóa ký lên đây.

Để ghi chi tiết thay đổi, tải thêm file Markdown cùng lần với IPA, đặt tên theo phiên bản/build, ví dụ `v0.12.1-build315.md`. Dùng các đề mục `## Tính năng mới`, `## Sửa lỗi`, `## Cải tiến`. Nếu không có ghi chú, hệ thống chỉ hiển thị thông báo chung, không tự đoán nội dung sửa lỗi.

Người dùng có bản app đã cấu hình nguồn cập nhật sẽ thấy bản mới khi app kiểm tra cập nhật. Việc ký/cài vẫn tuân theo phương thức cài trên thiết bị.
